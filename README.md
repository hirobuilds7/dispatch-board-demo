# 配車ボード デモ（dispatch-board-demo）

kintone + JavaScript による配車管理アプリの提案にあたり、
実際に触って動作を確認できるようにした画面です。

- **2D版（`index.html`）＝実務で使う画面**
  日／週の切替、車両別／ドライバー別の切替、未配車からのドラッグ割り当て、
  行をまたぐドラッグ＆ドロップ、時間の変更、重複チェック、色分け、
  クリックでの詳細確認・編集。ライト／ダークの切替つき。
- **3D版（`3d.html`）＝俯瞰して見せるための一枚**
  奥行きを時間軸に取り、車両レーンに配車を立体で配置。
  ⚠️ 見た目のインパクトはあるが、**重なりが見えにくく操作もしづらいため実務では2Dを推奨**。

## ライセンス

- タイムライン：[vis-timeline](https://github.com/visjs/vis-timeline)（Apache-2.0 OR MIT・商用利用可）
- 3D描画：[three.js](https://github.com/mrdoob/three.js)（MIT）
- **有償ライブラリ・有料プラグインは不使用。ライセンス費用は発生しません。**

## 実装で踏んだ落とし穴（メモ）

- `itemsAlwaysDraggable:{item:true,range:true}`
  既定 `false` だと「1回クリックして選択してから」でないとドラッグできず、初回操作が空振りする。
  配車の現場では1件動かすのに2アクション要ることになるため必ず有効化する。
- `showCurrentTime:false`
  既定 `true`。架空の日付を表示していると、実際の現在時刻を示す赤い縦線が出て紛らわしい。
- **グループラベルは HTML がサニタイズされ、インラインSVGはエスケープされ `class` 属性は剥がされる。**
  → アイコンはCSSの背景画像、スタイルは構造セレクタで当てる。
- `groupHeightMode:"fixed"` 行の高さを固定してドラッグ中に狙いがズレるのを防ぐ。
- 未配車一覧からボードへの投入は vis-timeline の標準では賄えず、HTML5 Drag and Drop で自前配線。

サンプルデータです。操作内容は保存されません。`noindex` 指定。
